## 🇹🇼 繁體中文

感謝您對 BrownDust2 Beat Helper 專案的興趣！我們歡迎各種形式的貢獻。

### 🤝 如何貢獻

#### 報告問題
- 使用 GitHub Issues 來回報 bug
- 請提供詳細的錯誤訊息和重現步驟
- 包含您的作業系統和 AutoHotkey 版本資訊

#### 功能建議
- 使用 GitHub Issues 來提出新功能建議
- 請詳細描述功能的使用場景和預期效果
- 考慮該功能對其他用戶的影響

#### 程式碼貢獻
1. Fork 此專案
2. 建立您的功能分支 (`git checkout -b feature/AmazingFeature`)
3. 提交您的變更 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 建立 Pull Request

### 📝 程式碼規範

- 使用 AutoHotkey v2 語法
- 遵循現有的程式碼風格
- 為新功能添加適當的註解
- 確保程式碼通過基本測試

### 🌐 多語言支援

如果您想添加新的語言支援：
1. 在 `lang/` 目錄下創建新的 `[語言代碼].ini` 檔案
2. 參考現有的 `zh-TW.ini` 和 `en-US.ini` 格式
3. 更新主程式中的語言選擇器
4. 測試所有界面文字是否正確顯示

### 📋 貢獻類型

- 🐛 Bug 修復
- ✨ 新功能開發
- 📚 文檔改進
- 🌐 翻譯和本地化
- 🎨 UI/UX 改進
- ⚡ 性能優化

## 🇺🇸 English

Thank you for your interest in the BrownDust2 Beat Helper project! We welcome all forms of contributions.

### 🤝 How to Contribute

#### Reporting Issues
- Use GitHub Issues to report bugs
- Please provide detailed error messages and reproduction steps
- Include your operating system and AutoHotkey version information

#### Feature Suggestions
- Use GitHub Issues to propose new features
- Please describe the use case and expected效果 in detail
- Consider the impact of the feature on other users

#### Code Contributions
1. Fork this project
2. Create your feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`)
4. Push to the branch (`git push origin feature/AmazingFeature`)
5. Create a Pull Request

### 📝 Code Standards

- Use AutoHotkey v2 syntax
- Follow existing code style
- Add appropriate comments for new features
- Ensure code passes basic testing

### 🌐 Multi-Language Support

If you want to add new language support:
1. Create a new `[language-code].ini` file in the `lang/` directory
2. Reference the existing `zh-TW.ini` and `en-US.ini` format
3. Update the language selector in the main program
4. Test that all interface text displays correctly

### 📋 Contribution Types

- 🐛 Bug fixes
- ✨ New feature development
- 📚 Documentation improvements
- 🌐 Translation and localization
- 🎨 UI/UX improvements
- ⚡ Performance optimizations
